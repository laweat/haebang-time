# 나의 해방시간

누구 좋으라고 일하는지 알려 드려요.

매달 나가는 고정비(월세, 통신비, 구독…)를 귀여운 **사장님**으로 바꿔서, 오늘 몇 시까지 사장님들을 위해 일하고 몇 시부터 나를 위해 일하는지 실시간으로 보여 주는 웹 앱이에요.

- 주소: https://laweat.github.io/haebang-time/
- 휴대폰에서 열고 **홈 화면에 추가**하면 앱처럼 쓸 수 있어요. (iPhone: 공유 → 홈 화면에 추가)
- 월급과 고정비는 **내 휴대폰 브라우저에만** 저장돼요. 서버로 보내는 값은 없어요.

이 저장소는 배포용 결과물이에요. `index.html`은 원본 프로토타입에서 `tools/build_pages.py`로 만들어요.
